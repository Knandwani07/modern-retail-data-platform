# 📊 Analytics and Visualization Results

This folder contains the business insights and visualizations generated from the curated retail dataset stored in Snowflake.

The charts help analyze sales performance, revenue trends, product popularity, and category-level distribution across the retail platform.

## Visualizations Included

| File | Description |
|--------|-------------|
| category-revenue-analysis.md | Revenue generated by each product category. |
| top-revenue-products.md | Highest revenue-generating products. |
| order-distribution-by-category.md | Order volume across product categories. |

These visualizations demonstrate how curated data can be transformed into actionable business insights for reporting and decision-making.
