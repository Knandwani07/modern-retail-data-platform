# Retrieve Storage Integration Details

## Purpose

This query displays the configuration and properties of the Snowflake storage integration.

It is used to retrieve the AWS IAM User ARN and External ID generated by Snowflake, which are required to establish a trusted relationship between Snowflake and AWS.

## SQL Query

```sql
DESC INTEGRATION retail_s3_int;
```

## Expected Outcome

The query returns the configuration details of the `RETAIL_S3_INT` storage integration, including:

- Integration name
- Storage provider
- Allowed S3 locations
- AWS IAM User ARN
- AWS External ID
- Integration status

## Key Values to Capture

| Property | Purpose |
|-----------|---------|
| `STORAGE_AWS_IAM_USER_ARN` | Snowflake-managed IAM user that will assume the AWS IAM role |
| `STORAGE_AWS_EXTERNAL_ID` | External identifier used to establish secure trust between AWS and Snowflake |

These values are required when updating the trust policy of the AWS IAM role.

## Why It Is Used

- Retrieves Snowflake-generated IAM credentials.
- Establishes secure trust between AWS and Snowflake.
- Enables Snowflake to assume the AWS IAM role.
- Required before creating external stages and loading data from Amazon S3.

## Next Step

Use the returned `STORAGE_AWS_IAM_USER_ARN` and `STORAGE_AWS_EXTERNAL_ID` values to update the trust relationship of the `SnowflakeS3AccessRole` IAM role in AWS.
