# 🔍 Athena Queries

This folder contains the Amazon Athena SQL queries used to validate, analyze, and generate business insights from the curated retail dataset.

These queries are executed against the `retail_curated` database and help verify data quality, measure business performance, and create visualizations for reporting.

---

## 📁 Query Overview

| File | Purpose |
|--------|---------|
| `validation-query.sql` | Validates the curated dataset by checking record counts and data consistency. |
| `category-distribution.sql` | Analyzes the distribution of orders across product categories. |
| `revenue-by-category.sql` | Calculates total revenue generated by each product category. |
| `top-products-by-revenue.sql` | Identifies the highest revenue-generating products. |

---

## 🎯 Why These Queries Are Important

These queries help:

- Validate successful data ingestion and transformation.
- Verify data consistency across AWS Glue, Athena, and Snowflake.
- Generate business insights from retail sales data.
- Identify top-performing categories and products.
- Support dashboard creation and reporting.

---

## 📊 Analytics Performed

The queries in this folder are used to produce:

- Order Distribution by Product Category
- Revenue by Product Category
- Top Revenue-Generating Products

These insights demonstrate how the curated retail dataset can be used for business intelligence and decision-making.
