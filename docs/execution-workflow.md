# 🚀 Execution Workflow

This guide provides a high-level overview of the project execution flow, showing how data moves from Amazon S3 through AWS analytics services and into Snowflake for reporting and analysis.

---

## Execution Workflow

### 1. Create the Data Lake

Create an Amazon S3 bucket and organize it into:

```text
raw/
├── customers/
├── products/
└── orders/

curated/

athena-results/
```

The raw layer stores source datasets, while the curated layer stores transformed data generated by AWS Glue.

---

### 2. Configure IAM Access

Create the required IAM roles and policies for:

- AWS Glue
- AWS Lambda
- Snowflake Storage Integration

These permissions enable secure access between AWS services and Amazon S3.

---

### 3. Upload Source Data

Upload the datasets to the S3 data lake:

```text
raw/customers/
raw/products/
raw/orders/
```

These files serve as the source data for the pipeline.

---

### 4. Create the AWS Glue ETL Job

Configure an AWS Glue job to:

- Read raw order data from S3
- Apply transformations
- Generate curated datasets
- Write transformed output to:

```text
curated/
```

---

### 5. Configure Amazon Athena

Create an Athena database and table to:

- Query curated datasets
- Validate transformed records
- Perform data quality checks

Athena provides serverless access to the data stored in Amazon S3.

---

### 6. Automate the Pipeline with AWS Lambda

Deploy the Lambda function:

```text
trigger-retail-pipeline
```

The function automatically triggers the AWS Glue ETL job, enabling on-demand pipeline execution.

---

### 7. Configure Snowflake

Create the required Snowflake resources:

- Database
- Schema
- Warehouse
- Storage Integration
- External Stages
- File Formats

These components allow Snowflake to securely access data stored in Amazon S3.

---

### 8. Load Product JSON Data

Load the raw product dataset into Snowflake:

- Create a JSON file format
- Create an external stage
- Load data into the `products_raw` table
- Validate the load

This demonstrates Snowflake's support for semi-structured data.

---

### 9. Load Curated Orders Data

Load the curated Parquet dataset into Snowflake:

- Create a Parquet file format
- Create an external stage
- Create the `orders_curated` table
- Load data using `COPY INTO`

The dataset is now available for analytics and reporting.

---

### 10. Validate the Data

Verify successful ingestion by:

- Comparing row counts
- Querying loaded tables
- Confirming stage access
- Reviewing load results

Validation ensures consistency between AWS Glue, Athena, and Snowflake.

---

### 11. Run Analytics Queries

Use Snowflake and Athena to generate insights such as:

- Revenue by Product Category
- Top Selling Products
- Revenue by City

These queries demonstrate the business value of the retail data platform.

---

### 12. Visualize Results

Create charts and dashboards from the curated datasets to analyze:

- Sales performance
- Customer distribution
- Product trends

---

### 13. Clean Up Resources

To avoid ongoing AWS and Snowflake charges, delete:

- AWS Glue Jobs
- AWS Glue Crawlers
- Lambda Functions
- Athena Tables and Database
- S3 Bucket and Objects
- IAM Roles and Policies
- Snowflake Database
- Snowflake Warehouse
- Storage Integrations
- External Stages
- File Formats

---

## Architecture Summary

```text
Amazon S3 (Raw Data)
        │
        ▼
AWS Glue ETL
        │
        ▼
Amazon S3 (Curated Data)
        │
        ├────────► Amazon Athena
        │
        ▼
Snowflake Storage Integration
        │
        ▼
Snowflake Tables
        │
        ▼
Analytics & Reporting
```

This workflow demonstrates a modern retail data platform using AWS for data engineering and Snowflake for cloud data warehousing and analytics.
